# Multiple Disease Prediction System using Machine Learning

## 📌 Overview
This project predicts the likelihood of multiple diseases using trained Machine Learning models.

## 🧠 Diseases Covered
- Breast Cancer
- Diabetes
- Heart Disease
- Parkinson’s Disease
- Lung Cancer

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit (for web app)

## 🚀 Features
- Predicts 5 diseases in one system
- Simple and user-friendly interface
- Accurate ML models
- Real-time prediction

## ▶️ How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py

## 📊 Models Used
- Logistic Regression
- Decision Tree
- Random Forest
